# NEXUS-COMMERCE

## E-Commerce Website with Mini CRM Dashboard

A responsive e-commerce website developed for the
Beyond Prompting Capstone Assignment 2026,
organized by GDGoC CUI Wah.

## Live Website

https://nexus-commerce-capstone-eta.vercel.app

## Features

### Customer Storefront
- Responsive product catalog
- Product search and category filtering
- Product details and availability
- Shopping cart with quantity management
- Simulated checkout
- Order confirmation

### Merchant CRM
- Merchant login interface
- Order management dashboard
- Customer and inquiry records
- Order status updates
- Summary statistics

## Installation

Clone this repository:

https://github.com/taqekhanzakinoor-debug/nexus-commerce-capstone

Open the project folder in VS Code.

Run:

    npm install
    npm run dev

Open the localhost address displayed in the terminal.

## Limitations

This is a capstone demonstration application.

- Checkout does not process real payments.
- Merchant login is not secure server-side authentication.
- Orders are stored in browser localStorage.
- A shared production database is not implemented.

## Deployment

The website is deployed on Vercel and maintained
through GitHub.
